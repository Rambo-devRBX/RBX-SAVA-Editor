# RBX SAVA Editor

**A custom-built PUBG Mobile Activity Editor by RBX.**

RBX SAVA Editor is an independently developed Windows application designed to provide users with a customized environment for managing and editing PUBG Mobile activity-related configuration settings.

Built with Python, the application features a custom interface and an independent editing workflow.

## Features

- Custom-developed editing interface
- Activity configuration management
- Direct editing environment
- RBX-exclusive design and branding
- Lightweight Windows application
- Independent development by RBX
